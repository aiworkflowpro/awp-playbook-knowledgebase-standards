# Prompt Writing Glossary

> One concept has one term. This glossary adds no rule.

| Term | Meaning |
|------|---------|
| Prompt | Reusable instruction text given to a language model |
| Eight-section format | The single-generation framework for role, task, context, method, input, output, constraints, and self-check |
| Tool prompt | A prompt for report fields, retrieval, rewrite lists, or interfaces; it can fix outputs and thresholds |
| Creative prompt | A prompt for posts, articles, or role-based writing; it uses a small contract and dynamic sampling |
| Reverse outline paste | The anti-pattern of using a list of article headings directly as the output structure |
| Output definition | Name the deliverable instead of asking for vague analysis or improvement |
| Multi-file system | A prompt system that combines method, persona, vocabulary, and other coordinated files |
