
## Standards

This project keeps its writing standards in `standards/`. Before a task listed below, read the
standard for it, follow it, and check the result against its checklist before you answer.

| Task | Read first |
|---|---|
| Write or change a standard | `standards/awp-meta-authoring-standard/std-core-chapter-skeleton.md` |
| Write a reusable prompt | `standards/awp-prompt-writing-standard/prompt-format-eight-part.md` |
| Build or change a Skill | `standards/awp-skill-development-standard/skill-core-development-standard.md` |

- The prompts from the video are in `../awp-playbook-knowledgebase-standards/prompts/` (list in its `README.md`). Use the
  "Use it in your own project" version of each prompt.
- Each package has a `CLAUDE.md` index. Open it to find supporting files; read files in
  `advanced/` only when the main file points you there.
- Treat the standards as read-only. Follow them; change them only when asked.
- A new standard goes in `standards/` as its own package, named in four parts:
  `awp-{topic}-{class}-standard/` (replace `awp` with your own prefix if you like).
- Register what you add: a new standard, prompt or Skill gets a row in the table above. A file
  no index points to is a file the next session will not find.
