# 15 · Ask for a complete prompt

- **Purpose:** you do not write the eight parts yourself. You name the standard and the task,
  and the agent drafts the prompt. The first draft fills five of eight parts.
- **In the video:** 03 Prompt standard, "a request becomes a complete prompt through questions".

## As shown in the video

```text
Use the prompt standard in standards/ to write a complete eight-part prompt: a professional video script.
```

## Use it in your own project

Replace the task at the end with your own. Follow up with [prompt 16](16-interview-me.md) to
fill the missing parts.

```text
Working directory: your project root. Run pwd first and cd there if you are not in it.

Use the prompt standard in standards/ to write a complete eight-part prompt: {your task}.
Save it to standards/prompts/{task-name}.md.
```
