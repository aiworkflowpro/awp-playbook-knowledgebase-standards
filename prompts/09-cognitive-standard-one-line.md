# 09 · The same request in one line

- **Purpose:** the short form of [prompt 08](08-write-cognitive-discipline-standard.md). Two
  inputs, the meta-standard and the agent's known weaknesses, produce a new standard.
- **In the video:** 02 Meta standard, "the meta-standard derives standards; standards drive
  tasks" (the "Your prompt" card).

## As shown in the video

```text
Using the meta-standard and my agent's cognitive flaws, create a cognitive discipline standard.
```

## Use it in your own project

It works once the meta-standard is installed and listed in your `AGENTS.md` (Quick Start does
both). For a predictable result, use the full version in
[prompt 08](08-write-cognitive-discipline-standard.md).
