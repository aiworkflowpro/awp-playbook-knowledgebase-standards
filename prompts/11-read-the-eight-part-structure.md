# 11 · Read the eight-part structure

- **Purpose:** before writing a prompt, show the agent the structure every prompt follows:
  metadata header, Role, Core Tasks, Input Information, Workflow, Examples / Templates, Output
  Standard, Refusal Scenarios.
- **In the video:** 03 Prompt standard, the A/B demo, first session.

## As shown in the video

On screen the standards sit in `knowledge-base/standards/`. After the Quick Start they are in
`standards/` in your project.

```text
Read the prompt framework: section 3 of knowledge-base/standards/awp-prompt-writing-standard/prompt-format-eight-part.md.
```

## Use it in your own project

```text
Working directory: your project root. Run pwd first and cd there if you are not in it.

Read the prompt framework: section 3 of standards/awp-prompt-writing-standard/prompt-format-eight-part.md.
List the eight parts in order.
```
