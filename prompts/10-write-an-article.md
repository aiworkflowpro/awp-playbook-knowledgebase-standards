# 10 · Same prompt, different context

- **Purpose:** a short prompt leaves the agent to fill in everything else. Given the same words,
  two agents with different context produce different articles.
- **In the video:** 03 Prompt standard, "same prompt, different context".

## As shown in the video

```text
Write an article about AI agents
```

## Use it in your own project

Run it in two sessions: one in an empty folder, one in a project whose `AGENTS.md` describes
your audience and voice. Then write the request as an eight-part prompt with
[prompt 13](13-eight-part-prompt-and-run.md).
