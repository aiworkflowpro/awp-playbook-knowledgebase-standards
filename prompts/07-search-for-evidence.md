# 07 · Make the agent look for evidence

- **Purpose:** one rule from the cognitive discipline standard in action: an idea is a hypothesis
  until outside evidence supports it. The agent searches, finds four competitors and drops the
  track.
- **In the video:** 02 Meta standard, "clear out the common ideas, investigate, then decide".
- **Run it:** in the same session, right after prompt 05. It follows up on the previous answer,
  so a fresh session has nothing to work on.

## As shown in the video

```text
Now search the web for real evidence before you pick.
```

## Use it in your own project

Send it after the agent proposes ideas. It only works if your agent has a web search tool;
without one, ask it to mark every claim it cannot verify as unverified.
