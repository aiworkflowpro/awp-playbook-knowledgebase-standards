# 18 · Generate a Skill from your standard

- **Purpose:** "my specifications" means the Skill development standard. The agent reads it and
  writes a Skill that follows it; here it writes a 78-line `SKILL.md` first.
- **In the video:** 04 Skill standard, "from research to a capability of your own".

## As shown in the video

```text
Generate a skill based on my specifications, exclusive to Leo and AWP.
```

## Use it in your own project

Replace the names with your own. For a step-by-step build, use
[prompt 19](19-build-trailer-skill.md).

```text
Working directory: your project root. Run pwd first and cd there if you are not in it.

Read standards/awp-skill-development-standard/skill-core-development-standard.md. It is my
specification for Skills. Using it and the notes in research/, generate a {what it does} Skill,
exclusive to {your name} and {your brand}. Save it to skills/{skill-name}/.
```
