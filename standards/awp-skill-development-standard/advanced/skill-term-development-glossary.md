# Skill Development Glossary

> This glossary uses the same terms as the main standard. It adds no rule.

| Term | Meaning |
|------|---------|
| Skill | A Claude Code capability package with steps, scripts, and configuration |
| SKILL.md | The Skill entry file and its frontmatter |
| Runtime Contract | A declaration of runtime capabilities and model assets |
| Step | A schedulable execution unit with preflight checks and parameters |
| Change rule | Redesign for the current need; do not stack compatibility patches |
| Preflight | A Step 00 startup check and cache stage |
| Resume | Continue from saved run progress |
| Three-level configuration | Global, Skill, and run-time configuration layers |
| Context isolation | Load only the dimensions needed by the current step |
| Pattern | A P1–P11 scenario pattern |
| Child Agent | A delegated Agent execution unit with one purpose |
| Two credential modes | Local parsing and user-supplied fallback values |
| EDD | Error-driven development and testing |
| Forward-only change | Change the current behavior without a compatibility branch |
