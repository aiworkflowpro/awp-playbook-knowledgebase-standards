# AWP Standards Standard

> The standard for standards. It explains how to create and maintain every writing standard in the AWP knowledge base.

Read this before creating or changing any standard.

## Scope

Every standards folder and file under `standards/`.

## Document Index

| File | Purpose |

| `std-lifecycle-version-retire.md` | Standard lifecycle and versioning |

## Working Rule

Start with the shared shape.

Use direct pointers instead of copying the same full rule into two places.

Follow the lifecycle and review fields defined by the main standard.

Apply `std-style-language-contract.md` to every standard before release.
