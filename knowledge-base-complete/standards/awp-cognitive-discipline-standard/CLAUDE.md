# AWP Cognitive Discipline Standard

> Rules that force an AI agent to think beyond its training-data average. Defines seven predictable cognitive weaknesses of language models, one rule that defeats each, and a checkable threshold for every rule — plus an output gate of quality criteria. A framework standard (weakness → rule → threshold → output gate), not a step-by-step workflow.

## Scope

Open-ended discovery tasks — product ideation, market gap analysis, niche discovery, creative strategy. Not for mechanical execution or tasks with known correct answers.
